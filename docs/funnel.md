# Budget Reset — Funnel

Traffico Instagram/TikTok/YouTube → landing → Budget Reset gratuito → attivazione → email nurture → Budget Reset Solo PRO.

## Eventi consigliati
- `page_view`
- `generate_lead`
- `start_budget`
- `budget_completed`
- `goal_created`
- `offer_view`
- `checkout_started`
- `purchase`

## UTM
Usare `utm_source`, `utm_medium`, `utm_campaign`, `utm_content`, `utm_term`.

Il file `/content/reel-content.csv` contiene già un UTM Content univoco per i 30 contenuti.
